# Amazon-Style E-Commerce Application

An Amazon-style e-commerce web application developed as part of our internship project.

## Project Overview

This project is an Amazon-style e-commerce application designed to provide customers with a familiar online shopping experience.

The current customer-side application includes product browsing, product details, user authentication, shopping cart management, checkout, order management, and account features.

The frontend is built with React and Vite and uses Firebase Authentication and Cloud Firestore for authentication and data storage.
